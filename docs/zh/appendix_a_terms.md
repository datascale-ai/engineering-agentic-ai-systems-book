# 附录A 术语与缩略语

本附录汇总当前中文书稿中已经形成正式正文的核心术语。首次出现章节按书中首次给出实质定义或用于建立概念边界的章节登记；只有占位文本的章节暂不纳入。术语定义用于全书一致性检查，不替代正文中的论证、示例和适用条件。

“易混淆项”指出含义相近但不能互换的概念。英文术语采用本书统一译法；代码对象保留正文中的英文标识。后续章节转为正式正文后，应按首次出现顺序补充并复核本表。

## A.10 维护规则

1. 新术语只有在正式正文中获得定义后才进入本表，占位章节中的拟议术语不登记为已采用术语。
2. 同一概念跨章复用时沿用既有中文和英文，不另建同义条目；确需更名时记录兼容名称并全书检索。
3. “首次出现章节”指首次实质定义章，不以目录、前言或占位字段中的偶然出现为准。
4. 代码对象、事件名和文件名保持大小写与正文一致；普通英文术语使用小写，专有缩写保留规范拼写。
5. 易混淆项用于提示边界，不表示两个术语互为反义词。新增章节应检查本列中的区分是否仍与正文一致。
