# 后记与版本说明

本书把智能体看作持续与信息、工具、环境和人协作的系统。模型能力会变化，系统仍需解释目标、来源、权限、行动结果与责任。可运行材料的用途，是使这些决定可以被检查和讨论。

## 中文稿与配套材料

当前 D 部分版本为 `zh-draft-0.1`，日期 2026-11-09，覆盖 Ch14—17、Ch33—35 及相应篇级材料。正式页数需在统一出版模板中试排。中文先审阅，再统一翻译；团队独立审稿、项目模块接入与外部学生复现按实际进度登记。

代码入口为仓库 `examples/` 与 `projects/`，环境由 `pyproject.toml` 和 `uv.lock` 固定。SVG 保留可编辑文字与矢量对象，重建脚本位于 `examples/figures/`。原创教学政策、任务和代码沿用仓库 MIT 许可；外部论文、模型与第三方资料保留各自许可，不因引用而改变。

本地报告记录规则实验、真实检索与沙箱工具结果。模型自由生成、真实企业效率与生产部署只在有相应证据时报告，不与教学路径混合。

## 勘误与维护

读者反馈可附章节、小节、文件路径、输入、运行命令和实际结果，通过[项目仓库](https://github.com/datascale-ai/engineering-agentic-ai-systems-book)提交 issue 或 pull request。涉及数据权限或个人信息的材料应先按所属组织流程处理，再提供可公开的最小复现。

修订保留变更对象、来源、影响章节与验证命令。知识、工具、提示、模型与代码版本分开记录；已发布版本的更正说明保留，使旧结果仍可解释。[主题索引](topic_index.md)、[人名索引](name_index.md)与[附录 H](appendix_h_reading.md)提供后续阅读入口。
