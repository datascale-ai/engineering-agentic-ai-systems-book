# 第四篇：记忆、知识与智能体学习

智能体处理一次任务时，需要知道当前目标和未完成条件；跨任务工作时，需要保留适用经验与偏好；解释组织规则时，需要查找当前有权使用的知识；改变后续行为时，还需要证明更新有益。四类对象相互连接，却具有不同的来源、有效期与修改权限。

本篇以政策研究与费用申请助手为贯穿案例。Ch14 先建立当前任务的权威状态，Ch15 组织跨会话记忆，Ch16 把知识连接到可核验来源，Ch17 将失败与反馈转成有验证、可回退的变更。学习目标是让系统能够解释：这条信息为什么现在可以使用，谁能纠正它，它变化后哪些对象必须失效。

## 篇末综合练习

使用同一位员工的两次费用申请：首次有临时出发时间，第二次个人偏好已纠正；两次之间政策换版，第一任务的旧 worker 在取消后迟到。实现状态、记忆、知识和经验四个模块的最小连接。

交付一份事件时间线、一张当前状态、一组带来源记忆、两张证据卡和一条更新接受记录。验证临时偏好不外溢、旧政策不支持当前动作、取消任务不提交、删除后恢复不复活。至少保留一个材料不足的结果。

评分为对象与来源 25 分、作用域与版本 25 分、故障和恢复 30 分、复现与解释 20 分。教师答案与编辑记录存于本地 `editorial/part4/`，不进入读者网站。
