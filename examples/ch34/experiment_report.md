# 三项目实际执行报告

环境：本地Python3.12、SQLite，串行，50份原创政策、60任务；每项目独立临时库。
三项目各正确60/60、20工单；正常事件分别120/240/180。模型与远端业务调用均为0。
九类故障×三项目=27项全部满足目标工单不变量，逐项事件与拒绝原因见JSON。
八次并发同任务提交的行为测试断言唯一工单和唯一完成事件。

耗时是本机一次运行的暖路径，结果保存但不作吞吐、容量或生产SLO依据。
权限为合成部门配置，批准为夹具；真实认证、分布式租约、网络工具与人类独立运行尚未执行。
完整测试 `uv run --frozen pytest`，正常与故障 `uv run --frozen python examples/ch34/run_projects.py`。
