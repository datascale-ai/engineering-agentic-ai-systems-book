# 第九篇最终工程综合实践评分标准 (`final_capstone_rubric.md`)

本评分标准严格对应全书写作指导第 4.5 节与 Ch39-T4 要求，总分 100 分，使用与 Ch34 / Ch36—Ch38 同一套参考实现与数据资产（PRJ-1 / PRJ-2 / PRJ-3）。

## 1. 评分维度与客观依据（满分 100 分）

| 维度 | 满分 | 客观评分依据与核查产物 |
| --- | ---: | --- |
| 1. 干净环境复现 | 15 | 在全新目录按 README 完整执行构建、测试与演练命令；记录机器/OS/Python 版本、命令、退出码与运行时长；无本机绝对路径依赖 |
| 2. 任务与证据正确 | 20 | 独立读取 `service.sqlite` 与事件日志验证业务后置条件；每个任务保留 `task_id`、政策条款引用与预期对照；不以模型自述文本替代状态核验 |
| 3. 权限与副作用控制 | 20 | 高风险审批任务零越权写入；重连/崩溃恢复保持同一 `operation_id` 且唯一工单；取消后如实登记已提交副作用而非宣称撤销 |
| 4. 测试与回归门禁 | 20 | 运行 Ch37 行为测试与 Ch38 切片回归、OpenTelemetry 风格轨迹断言（TA-01—TA-05）及至少 8 类沙箱故障注入；受控缺陷可被捕获 |
| 5. 部署、故障与回滚 | 15 | 完成一次受控发布、一次配置错配/缓存残留故障注入与一次含代码+配置+数据+权限+缓存的完整回滚，并在回滚后执行业务恢复验收 |
| 6. 报告与适用局限 | 10 | 明确区分模拟 mock 验证与真实模型/生产环境；如实列出未验证项（真实 IAM、跨主机网络分区、真实流量压测等），无伪造数字 |

## 2. 直接退回条件（零容忍，不可由其他项得分抵消）

- 遗漏权限控制检查，或允许模型自由文本绕过审批直接写入；
- 无法在干净目录复现核心路径且未给出可定位原因；
- 伪造测试输出、跳过失败断言、篡改基线预期掩盖回归，或将 mock 控制验证宣称为真实生产容量/模型能力；
- 存在明文密钥进入日志、轨迹或发布包。

## 3. 基础必做与进阶可选任务

- **基础必做**：执行 `python examples/ch39/drill_runner.py` 完成 DRILL-01 至 DRILL-04 四项演练，提交 `release_report.md`、`ch39_drill_results.json`、回滚前后对比表与局限说明。
- **进阶可选**：(a) 在 `drill_runner.py` 中新增一种“数据库 schema 向前不兼容变更”故障，实现升级前快照校验与拒绝回退保护；(b) 将 Ch24 流式取消检查点接入 PRJ-3 预发布健康探针，并报告取消响应尾延迟。
