# 删除传播报告：u1:departure

实验：先建快照并热身缓存，再删除，再恢复旧快照。输入为合成偏好。

| 层 | 执行动作 | 实际状态 | 未覆盖 |
| --- | --- | --- | --- |
| 主记录 | 移除目标并置删除标记 | absent | 真实数据库副本 |
| 索引 | 移除目标 ID | absent | 分布式索引传播 |
| 缓存 | 世代递增、清空 | invalidated | 外部服务缓存 |
| 备份 | 保留快照，恢复时按标记过滤 | retained_until_expiry | 物理到期销毁未实现 |

恢复后目标查询为空；另一个用户的记录保持可读。断言见 `test_delete_invalidates_cached_result_and_restore`。
删除标记必须独立可靠保存；本实现仅内存演练，不提供灾难恢复保证。
