# 环境卡：表单与网格

版本 `environment-local-1`；实现唯一入口 `src/book_reference/environment_study.py:EnvironmentAdapter`。

| 字段 | 数字表单 A | 网格 B |
| --- | --- | --- |
| 目标 | 金额250、境内常规、教学申请，保存并唯一提交 | 从(1,1)到目标(1,4)，目标可按脚本更新 |
| 观测 | 字段、保存/提交状态、保存坐标、遮挡、测试批准、episode/版本/采集时刻 | 位置、目标、预知基础地图、当前障碍/未知格、episode/版本/采集时刻 |
| 动作 | fill、dismiss、save、submit；预检另有 cancel_pending | 四邻格 move；预检另有 cancel_pending |
| 反馈 | done、failed、rejected、pending、unknown；可按原动作ID查询 | 同左，done 还含已确认位置 |
| 权限 | 受信本地测试批准；不是真实业务授权 | 固定允许区域及接收端阻挡检查 |
| 时间 | 虚拟毫秒，观测/动作各50ms，查询100ms；保存延迟800ms | 相同基础时钟；延迟移动1000ms |
| 预算 | 每试次12业务/取消动作、20观测、20查询、30秒虚拟截止 | 同左 |
| 重置 | 有任何未决旧动作即拒绝；新试次新实例 | 同左 |
| 验收 | 外部读取字段、唯一提交和回执；未知不能自报完成 | 外部读取实际位置/目标；堵塞停止不算到达 |

O 只按第一次观测规划，接受动作确认中的版本和已确认位置更新，遇拒绝、明确失败、未知立即停止；它不为改善结果关闭接收端保护。C 重新观测、按需查询并规划，检查观测与已确认位置是否冲突。两个控制器都不能读取故障名称或完整评分状态。

策略日志、环境注入和独立评分在 JSONL 中分别标识。`score()` 独立检查已提交动作的前置快照，不能仅引用策略自报。`business_success` 要同时有策略的有据确认、外部后置条件和约束通过；另保留 `oracle.postcondition`，因此“提交已发生但反馈未知”不会被抹成从未发生。

A10/B10 保留旧 episode 的未决动作，重置被拒，取消未知、旧反馈被隔离并交接。该基本夹具演示隔离规则，不模拟真实异步设备控制器或持久跨进程队列。恢复时间从实际注入到第一个可核验继续步骤计，尚未恢复保留 null 和未恢复标记；所有时间均不是实测设备延迟。
